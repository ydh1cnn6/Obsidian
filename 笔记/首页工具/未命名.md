### 📅 日历
> 这里可以嵌入 Calendar 插件的代码块（如果你的主题支持），或使用 Dataview 列出本月的日记。
```dataview
LIST
FROM "Daily Notes"
WHERE file.day.month = date(today).month
SORT file.day DESC
LIMIT 7
```

### 🎲 随机漫游 (温故知新)
```dataviewjs
// 随机抽取 3 篇笔记展示
let pages = dv.pages().where(p => p.file.name != dv.current().file.name);
let randomPages = pages.sort(() => Math.random() - 0.5).slice(0, 3);
dv.list(randomPages.map(p => p.file.link));
```
